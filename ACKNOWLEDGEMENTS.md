# Acknowledgements

The cilia model in this repository began as a Nek5000 implementation, developed in the Integrative Simulations & Computational Fluids Lab at Arizona State University under the supervision of Dr. Yulia Peet, with partial support from NSF grant CBET-1944568. I am grateful for that foundation. The port to nekRS, the GPU work and the code in this repository are a separate project that I carried out independently.

I thank Dr. Tanmoy Chatterjee, who helped develop the actuator filament model for cilia-driven flows on which this code builds.

The simulations were run on the Sol supercomputer at Arizona State University.

This code is built on [nekRS](https://github.com/Nek5000/nekRS); I thank its developers.
